# 초기 학습 해석과 반복 문제: 이전 이력 → 원문 연구 → 직접 계산

사용자 최신 지시를 지속 연구 원칙으로 적용한다. 관련 문제가 생기면 먼저 이전 버전·실행·수정 이력을 읽고, 추가로 논문 등 1차 자료를 확인한 다음 저장값이나 작은 계산으로 판단한다. 작은 초기 실험의 품질 목표 미달을 모델이나 구조 전체의 실패로 확대하지 않는다. 기존 결과·퇴행·미달 기록은 보존한다. 사용자가 추가로 지시한 “절대 학습량이 아직 모자라니 검증에 너무 목매달지 말고 문제 해결되면 계속 학습해”에 따라 품질 지표를 학습 추세 관측에 사용하며, 수치·복구·디스크·프로세스·고정 실행 상한은 계속 지킨다. 에이전트는 사용하지 않는다.

## 이전 성과와 문제를 함께 보존

- **관계 예측 성과는 유효하다.** Typed QueryCount partial9의 같은 관측 조건에서 primary 100%(1024/1024), uniform 100%(512/512), oldrole 99.9452%(1823/1824), Q별 dev와 관측 transfer도100%였다. 제공된 역할·fuzzy closure·basis의 도움과 상관 위치라는 범위를 명시한다. 원래 typed 모델은 그대로 보존했다. 이 성과와 별도 자연문서 생성 분기의 초기 수준을 구분한다.
- 생성 V1의 깨진 UTF8에서 V2의 UTF8/EOS80/80, V3→V4 질문 쌍 정확도37.5→68.75%로 실제 개선이 있었다. V4의 새 표현 정확도 하락은 별도 과제로 남는다. 언어 encoder가 동결됐던 짧은 관계 태스크와 이번 자연문서 학습은 같은 실험이 아니다.
- 9월26일 문서 학습에서도 NLL은 개선됐으며 작은 기존 gate 초과를 전체 능력 붕괴로 확정하면 안 된다는 기록이 이미 있었다. Prompt/answer 분해와 BPE 경계 문제가 일부 원인을 설명했다. 현재는 byte 입력이므로 당시의 trim 규칙을 기계적으로 옮기지 않는다.
- 9월30일에는 EOS26/63→58/63이었지만 “No record” 상수 답변이 늘었다. **종료만 늘리는 수정은 충분하지 않다.** 내용·비EOF 오종료·자유 반복을 함께 관측한다.
- 기존 runtime에는 top-p, 부호를 고려한 repetition penalty, generated-only n-gram penalty와 exact-copy 예외가 있었다. 기존 단위 검사는 구현 확인이지 현재100M 모델의 생성 성과가 아니다. Byte에 단어 token용 벌점을 그대로 적용하면 공백·UTF8 구성 byte를 훼손할 수 있다.

## 추가 1차 연구와 적용 판단

1. [Unlikelihood training](https://arxiv.org/abs/1908.04319)은 반복 확률을 훈련 손실로 낮추는 방법이다. 정상 CE와 함께 쓰는 후보로 보존한다. 단어 수준 반복 정의를 byte 모델에 옮기는 계약은 별도 필요하다.
2. [Neural Text Degeneration](https://arxiv.org/abs/1904.09751)은 같은 모델에서도 decoding 방식이 반복에 영향을 준다고 보고한다. Top-p 비교는 학습 효과와 구분해 다룬다.
3. [DITTO](https://arxiv.org/abs/2206.02369)는 인위적으로 반복한 문장으로 반복 강화를 줄이는 훈련을 제안한다. 현재 원문에는12–42byte 문장 후보3027개/457문서가 계산됐지만, 이는 구두점 휴리스틱이며 완성 문장 검증이나 DITTO 재현 결과가 아니다.
4. [Self-contrastive training](https://aclanthology.org/2023.findings-acl.431/)은 초기 checkpoint가 반복 패턴을 빨리 익히는 현상을 다룬다. 초기 반복 관측을 구조 전체에 대한 최종 판정으로 쓰지 않을 근거가 된다. 우리 모델에서의 효과는 미측정이다.

## 계산 후 선택한 다음 학습

원래3271행/384675target bytes/512EOF에서 EOF symbol 비율은0.1329%다. CE EOF 가중치4의 상대 손실 mass는0.5296%다. 문서별 EOF/비EOF512개씩만 골라 가중치4를 주면2.0665%로 더 큰 재균형이 되므로 이번에는 원래 **전체 내용 자료를 유지하고 작은 가중치4**를 선택한다. 이 산술은 gradient 기여나 원인 증명이 아니다.

V7은 V6 최종 model·populated Adam·scaler·모든 RNG를 보존하고 새 유한 순열62/63으로 **두 epoch,818attempt/6542행 재노출/769350target bytes/1024EOF**를 추가하는 새 한정 실행으로 준비했다. 같은512문서 재노출이며 새6542문서가 아니다. 새 LR base는 language5e-6/기타1.5e-5이고 새로운818attempt cosine으로 명시한다. CE에서만 실제 EOF 가중치4, 비가중 symbol 수 정규화를 사용하며 VMSE/clean 손실과 실제 추론은 유지한다. Runtime EOS 강제 삽입이나 정답 길이 종료는 쓰지 않는다.

기존 관측 dev의 저장 final 자료를 새 baseline으로 명시적으로 재사용한다. 중간 품질 gate/반복 baseline 없이 학습을 진행하고 마지막에 NLL·비EOF 오종료·자유 반복·내용을 관측한다. 실행 오류·수치 이상·디스크·고정 예산 종료는 유지한다. 새 계산 상한은 training31084+NLL1998+자유생성최대1100=34182calls, cap35000/900초/reserve90/출력8GiB다. 이전 실행의 시간·호출·잔여 update를 재사용하지 않는다. 학습 완료와 실제 능력 결과는 실행 뒤 별도로 기록한다.
