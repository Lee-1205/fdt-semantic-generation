# Codec 의미성 및 디노이저 학습 상태 심화 검토

2026-11-14. ROOT 직접, 기존 저장 문장과 코드·결과만 계산했다. 이 분석 자체의 모델 forward/optimizer/GPU 호출은0이다. 타이머는 삭제 상태를 유지한다. 후속 사람 지시에 따라 별도로 ‘전체 원문의 왕복 검증→통과 TRAIN 의미만 분리→디노이저 단독 학습’ 절차를 준비한다. 아래 계산은 그 절차의 새 학습 성과가 아니다.

## 현재 판단

**지금의 나쁜 사고 답변은 ‘기존 의미 공간이 쓸 수 없다’보다 ‘새 디노이저가 입력 조건으로부터 답을 만들고 여러 단계 동안 유지하는 동작을 충분히 학습하지 못했다’는 설명을 우선 지지한다.** 숫자 확률을 산출할 비교 실험·likelihood는 없으므로 임의의 확률을 붙이지 않는다. 실제 업데이트가 전혀 없었다는 뜻도 아니다. 가중치·Adam·RNG 검증과 초기 NLL 개선은 실제 학습이 있었음을 확인한다.

언어 codec의 미인증 범위를 지적하는 것과 그 범위를 현재 사고 실패의 직접 원인으로 지목하는 것은 다르다. 앞선 보고서의 ‘의미 공간 인증은 아직 없다’를 ‘의미가 없다’로 해석하면 잘못이다.

## 1. 장문의49byte 오류는 구체적으로 무엇인가

V88의 두 원문과 실제 복원문 전체를 위치별로 비교하고 모든49개 오류 문맥을 읽었다. 기존 scorer의 작성 문법을 사후 score에만 사용해2,718개 사건의 필드를 다시 계산했다. 정답 필드·위치가 NN 입력이 되는 것은 아니다.

| 분류 | 손상 byte 수 | 예시/해석 |
|---|---:|---|
| 이동 수량 |13|7→6,17→16,26→+6,9→j 등 |
| 상자 잔여량 |2|9→b |
| 사건 번호 |7|129→1+9 등, 참조 식별자 손상 |
| 행동 주체 |2|Cyril→Ckril,Fiora→2iora |
| 물건 이름 |7|silver→s lver |
| 이동 동사 |5|moved→roved |
| 목적지 명사 |9|drawer→draber |
| episode 단어 |2|epidode/epitode |
| 구분기호 |2|세미콜론→m |
| 합계 |49|동일 사건의 여러 오류를 독립 사건으로 중복 세지 않음 |

49개 중 수량·잔여량15개를 더 나누면, **3개는 정상적인 unsigned 정수가 다른 값으로 바뀌었고,2개는 부호 있는 정수로 읽으면 다른 값이 됐으며,10개는 정상 정수로 파싱할 수 없는 표기**다. `7→6`은 의미가 바뀐 명백한 예다. `draber`는 사람이 문맥으로 drawer라고 복구할 여지가 있지만, 이를 자동으로 원래 단어라고 치환해 인증하지 않았다.

이번 두 문서에서는 **not 토큰과 before/after 시간관계 토큰의 손상은0**이다. ‘숫자·관계·부정 한 곳도 사실을 바꿀 수 있다’는 일반적 주의를 이번49개 모두에 부정/관계 반전이 있었던 것처럼 표현해서는 안 된다. 색상, checker, 부정문의 주체 등 검사한 다른 필드도 이 비교에서는 그대로였다.

전체2,718개 사건 중43개에서 선택한 필드 문자열 중 하나 이상이 달랐고,**2,675개(98.41795%)는 선택한 필드 묶음이 모두 같았다.** 사건 본문 byte가 한 곳이라도 다른 것은45개다. 구분기호2개는 scorer의 사건 본문 범위 밖이다. 출력 자체를 엄격한 문법으로 파싱할 수 있는 것은2,684개다. 문법상 정상이어도7이6이 된 문장은 사실이 틀릴 수 있다.

이98.42%는 ‘사람의 모든 의미 판단 정확도’가 아니다. 작성 문법의 고정 필드를 원문 위치와 정렬한 보존 수치다. 새 자연문서·새 관계에 일반화된 비율도 아니다. 다만 전체 문자열 일치0이라는 설명보다 **어느 정도의 구조적 내용을 보존했고 어디가 손상됐는지**를 훨씬 잘 보여준다.

이 다섯 패턴이49개 중30개다. 단순히 문맥이 길어질수록 의미가 사라지는 모습보다, **반복되는 lexical feature와 위치별 출력 결정 경계**의 문제를 먼저 의심할 근거다. 현재 출력기의 마지막 Linear는16개 byte role마다 다른 class row를 사용하므로 코드 구조와도 맞는다.

## 3. 문장 길이에 비례하는 의미 표현은 결함인가

**그 자체로 결함이 아니다.** 서로 독립적인 사실이 많이 들어 있는 긴 문서는 짧은 문서보다 많은 내용을 저장해야 한다. 디지털 유한 정밀도 표현으로 모든 L-byte 입력을 무손실로 구별하려면, 표현의 경우의 수가 입력의 경우의 수보다 작아서는 안 된다. 일반 byte열 전체를 대상으로 하면 적어도8Lbit의 구별 용량이 필요하다. 자연어의 허용 의미만 대상으로 한 실제 하한은 이 단순 byte열 상한 계산과 다르다.

따라서 ‘local512 FP32가16byte당2,048byte여서128배’라는 앞선 계산은 저장 형식의 크기 비교다. 의미성이 없다는 증거, 무조건 지나친 용량이라는 판정, 실제 entropy 추정에 사용할 수 없다. distributed representation이 원래 입력보다 많은 수치 원소를 쓰는 것은 가능하다.

진짜 미확인 지점은 **그 많은 표현이 사실·관계의 연산 가능한 구조를 형성했는지, 표면 순서를 다른 부호로 보존하는 데 주로 쓰이는지**다. 두 성질이 함께 있을 수도 있다. 복원 성공은 필요한 정보의 가용성을 지지하지만 두 성질의 비율을 결정해 주지 않는다.

또한 ‘같은 뜻의 두 문장은 완전히 같은 전체 latent’와 ‘각 원문을 글자까지 그대로 복원’은 그대로는 동시에 요구할 수 없다. x1≠x2이고 E(x1)=E(x2)이면 고정 D는 두 입력에서 같은 출력을 내므로 둘 다 원문과 일치할 수 없다. 예를 들어 능동/수동 표현이 같은 사건을 말해도 원래 문구는 다르다.

필요한 것은 전체 표현의 무조건적 동일성이 아니라, **같은 사실은 같은 사실로 읽고, 문체·표현 차이는 따로 보존할 수 있는 구조**다. 이런 구분이 지금 별도 subspace로 구현·인증됐다는 뜻은 아니다. 별도의 네 번째 memory나 일반 문장의 Exact 복사를 추가해야 한다는 제안도 아니다. 현재 fuzzy local/global 표현 안에도 내용·표현 정보가 함께 담길 수 있다.

[Locatello 등의 연구](https://proceedings.mlr.press/v97/locatello19a.html)는 비지도 representation의 식별에 모델·자료의 가정이 필요함을 보여준다. 그 정리는 현재 FDT의 불가능성이나 의미 결여를 증명하지 않는다.

## 4. 지금은 디노이저가 덜 학습됐다는 가설을 우선한다

### 입력·출력 고정 상태에서의 대조

- 정답의 실제 E(Y)를 고정 D에 넣은31개 경우,599개 내용 byte는 모두 기대 prefix로 읽혔다. 종료가 잘못된 한계는 별도로 남는다.
- 같은 D가 실제 디퓨전16단계의 결과를 받으면 대다수 문장이 깨졌다.
- V106에서는 같은 입력·잡음·D에서 unknown 두 건이1단계에서는 정확했지만16단계에서는 깨졌다.
- D/E/메모리 weight와 buffer는 사고 학습 중 전부 동일했다.

이는 D가 필요한 문장을 전혀 표현하지 못한다는 설명보다, Rθ가 적절한 영역의 의미 상태를 만들고 유지하지 못한다는 설명을 우선 지지한다. 다만 unknown은 상수 정답이므로 관계 추론 증거는 약하고, 긍정 두 사례는1단계부터 틀렸다. 입력 Zx의 관계 정보가 충분히 읽힐 수 있는지는 여전히 독립적으로 미인증이다.

### 학습 loss가 좋아 보여도 추론 동작은 덜 학습될 수 있다

| V103 TRAIN4 조건 | 평균 byte CE | 그 상태에 정답 정보가 있는가 |
|---|---:|---|
|정답에 작은 noise, t=.05|0.00646|많이 남아 있음|
|t=.5|0.13493|일부 남아 있음|
|t=.95|1.95698|적게 남아 있음|
|정답 없이 실제16step|5.54082|정답 condition 없음|

스케줄에서 t=.05의 α≈0.9969,σ≈0.07846이다. ‘정답 정보의99.69%가 남는다’는 정보량 계산은 아니지만, clean 신호의 계수가 큰 쉬운 복원 조건임은 분명하다. 이때 낮은 CE만으로 입력 질문을 해석해 답을 새로 형성하는 능력이 학습됐다고 볼 수 없다.

새 Rθ의 실제 학습은960update, 약227.106 CPU worker초,384개 상관 TRAIN의20회 노출이다. 초기 NLL 개선이 있었으므로 학습0/수치 전면 실패는 아니다. 반면 짧은 시간·작은 자료만으로 충분한 학습이 됐다고 인증할 근거도 없다. 시간만으로 필요한 update 수를 산출하거나 ‘더 돌리면 반드시 해결’이라고 말하지 않는다.

###16번 반복하면 왜 더 나빠질 수 있나

입력에 대해 고정된 centre/scale로 정규화한 r에 대해, 현재 sampler의 한 step은 다음과 같다.

`r_next = cos(δ) r − sin(δ) vθ(r,t,X)`

16등분이면 δ=π/32,cosδ≈0.995185,sinδ≈0.098017이다. 이상적인 경로의 velocity와의 오차를 η,현재 위치 오차를 e,국소 Jacobian을 J라 두면 선형 근사에서:

`e_next ≈ (cosδ I − sinδ J) e − sinδ η`

현재 학습 목적은 이 전체 연산이 실제 도달 상태에서 오차를 줄이도록 보장하지 않는다. 각 step의 작은 bias가 누적되거나 이전 오차가 커질 수 있다. 실제 J나 Lipschitz 상수를 이번에 측정한 것은 아니므로 증폭 배율 수치는 만들지 않는다.

정답에 가한 Gaussian noise의 상태를 학습하는 표준 목적은 정당한 diffusion 학습 방식이다. 전체 sampler를 반드시 역전파해야만 한다는 주장은 틀리다. 하지만 **현재처럼 모델이 불완전하게 fit된 상황**에서는 학습 상태와 자기 예측으로 도달한 상태의 차이가 중요하다. 이 문제는 [Input Perturbation, ICML2023](https://proceedings.mlr.press/v202/ning23a.html)와 [Consistent Diffusion Models, NeurIPS2023](https://papers.neurips.cc/paper_files/paper/2023/hash/831406cfe7e4a0aed5ac5c8a8389d1f5-Abstract-Conference.html)에서도 다뤄진다. 이미지 연구의 개선 수치나 해결책이 FDT에서도 그대로 성립한다는 뜻은 아니다.

V106의 TRAIN4 평균 byte CE도1step1.4308→4step3.3162→16step3.3599로 나빠졌다. 작은 선택 사례이며 단계수에 따라 time grid도 변한다. 전체 의미 공간보다 현재의 학습된 vector field/샘플러 조합을 먼저 점검할 이유다.

## 5. 사람의 새 제안을 반영한 분리 실험

최신 지시는 모델들을 함께 학습하지 않고 전체 데이터의 언어→의미→언어 검증을 먼저 수행해, 일치한 자료의 의미만 쓰라는 것이다. 현재 사고 자료 전체는 TRAIN384+DEV96=480원문이다. 이전 V95에서 실제 E(X)와 source-only 메모리 snapshot을 이미 저장했으므로 새 E 호출 없이 현재 고정 D로480개를 검사할 수 있다.

첫 선별 기준은 **UTF8 byte 완전 동일+정상 UTF8+모델이 EOS 출력**으로 사전 고정한다. prefix만 일치하거나 뒤에 잡음이 붙은 경우는 통과시키지 않는다. normalized/의미 유사 결과는 별도 진단으로만 남긴다. 이 보수적 기준은 검증된 의미로 디노이저 자체를 분리 시험하기 위한 선택이며, 앞으로 의미 보존 전체의 유일한 기준으로 삼는다는 뜻은 아니다.

통과한 TRAIN 원문의 E(X)만 loss-side clean 의미로 삼아, 처음에는 noise→원래 의미 복원을 학습한다. 입력·K_P/K_C/K_E·binding·D는 전부 고정한다. DEV는 학습에 넣지 않으며 전체96개 결과와 codec 통과 여부별 결과를 구분한다. 통과 부분집합의 높은 점수를 전체 자료 능력으로 보고하지 않는다.

이 identity 의미 복원은 관계를 추론해 다른 답 의미를 만드는 것보다 쉬운 통제다. 성공하면 Rθ가 이 codec의 latent geometry를 다룰 수 있다는 근거가 되고, 실패하면 복잡한 질문-답 매핑 이전의 denoising 학습 문제를 우선 살필 수 있다. 성공해도 독립 사고·관계 이해·일반 NLU의 증거로 세지 않는다. 통과 자료가 없거나 너무 좁으면 이를 그대로 보고하며 선별 조건을 몰래 완화하지 않는다.

기존31개 짧은 정답의 D(E(Y))는 알려진 EOS 문제로 전체 일치0이다. 그러므로 이를 검증된 답 의미인 것처럼 선별했다고 하거나, 원문 E(X)의 self-denoising 성공을 E(X)→E(답변)의 성공으로 바꾸어 부르면 안 된다.
