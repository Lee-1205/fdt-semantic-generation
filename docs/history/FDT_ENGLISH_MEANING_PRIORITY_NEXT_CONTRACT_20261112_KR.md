# 영어 의미 우선 후속 계약 — 2026-11-12

최신 사람 지시: 영어만 우선하며 의미 정확도를 중심으로 진행한다. 한국어는 보류한다. 전체 문자열 일치·바이트 정확도는 보조 지표이며 완벽한 문자 일치를 모든 작업의 통과 조건으로 삼지 않는다.

현재 V67 모델은 제한된 작성 영어 단문 24개에서 핵심 의미 유지로 수동 판독됐다. 장문의 244개 사건 묶음 중 1개 인물 참조가 불확실하고 기록번호 2개도 손상됐다. 자연 OWT 문맥에는 날짜·수량/범주·인명 손상이 남는다. 이 제한을 유지하며 추상 의미 공간 전체 완성이나 일반적 의미 정확도 100%로 확대하지 않는다.

후속 작업은 실제 문장→퍼지 상태→문장 사이클에서 행위자/대상/관계/부정/수량/시간/순서/내용 누락과 추가를 우선한다. 원문 대비 충실성을 보며 원문의 실제 세계 사실 여부를 새 요구로 끼워 넣지 않는다. 같은 의미의 자연스러운 다른 표현을 정답으로 인정할 수 있어야 한다. 자동 parser가 이해하지 못하는 의역은 오답이 아니라 수동 검토 대상으로 남긴다. 확인할 수 없는 고유명사·수량 변경은 불확실성으로 남긴다.

V59–V62의 역할/관계 예측은 보조 이력이며 단독으로 현재 언어 사이클의 의미 형성을 증명하지 않는다. V59의 pre-bank factor 우회, V61/V62의 decoded factor와 실제 기억값 구분, 짧은 작성 문장 coverage/role overlap 문제를 먼저 참고한다. 새 의미 보조 loss를 검토한다면 실제 bound K_C/Commit를 통과해 언어 표현과 연결되는지 확인하고, 별도 사실 head의 개선만으로 성공을 보고하지 않는다. 이전의 16바이트 position 기여를 행위자/목적어 역할로 재명명하지 않는다.

Exact는 미래의 명시적 정확 복사 요청 때만 내부에서 사용한다. 현재는 일반 의미·문장·이름·숫자를 자동 Exact로 옮기지 않는다. 기본 퍼지 K_P/문맥 퍼지 K_C/Exact K_E 세 구조를 유지하며 K_E는 휴면 NULL이다. Gold 역할/정답 의미/정답 span/regex 결과는 훈련 loss 또는 사후 score에만 허용하고 NN 추론 feature로 사용하지 않는다. 디코더는 확정된 Commit만 읽으며 raw H/원문 문자열/정답 prefix/목표 길이 우회는 금지한다.

원문 표현을 보존해야 하는 로컬 퍼지 정보 전체에 무조건 paraphrase 불변성을 강제하지 않는다. 추상 의미의 보존과 실현 형태의 정보를 같은 것으로 취급하지 않으며, 필요하면 기존 K_C/Commit 안의 용도 구분을 CPU 계약부터 검토한다. 새로운 원문 우회, 네 번째 메모리, 전체 Exact 복사 기능을 자동 추가하지 않는다. 의미 디노이징은 아직 별도의 후속 학습 단계로 남긴다.

자료는 기존 허가된 영어 TRAIN 또는 독립 작성 자료를 사용한다. V66의 52개 평가 문장과 관측 개발 원문/정답을 훈련에 편입하지 않는다. 새 후보는 하나의 구체적인 의미 보존 문제와 유한한 학습 범위를 먼저 정한다. 동일 baseline, 광범위 audit, 같은 평가를 반복하는 것을 무한 선행 조건으로 만들지 않는다.

새 실행은 새로운 목적/코드·자료 SHA/실제 plan schema/필요한 CPU 학습·복구 계약/실제 worker preflight와 독립 OS 검토/고정 time-call-row-epoch-output cap/자원/중복 0을 ROOT가 확인한 뒤 한 번만 실행한다. 과거 V64/V65/V66/V67의 남은 시간·호출·update는 재사용하지 않는다. C: 100GiB 여유 보호, 모든 이전 source/weights/Adam/RNG/실패 보존, ROOT 직접/no agents, E2 final/registry 금지, 종료 후 모든 owned/proxy 종료 확인 규율은 유지한다.

이 문서는 사람 승인을 기다리는 차단 장치가 아니라 다음 연구의 범위 계약이다. 아직 새로운 의미 학습 후보/runner/plan/seal/GPU는 만들지 않았다.
