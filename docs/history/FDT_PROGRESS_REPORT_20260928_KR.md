# FDT 검사·개선 누적 보고 — 2026-09-28

## 요약

Exact가 실제 생성에 연결됐고, 올바르게 승인한 payload의 정확 운송은 확인했다. 공백 출력과 종료 동작도 개선됐다. 그러나 질문 이해·근거 답변·자연어 전개와 학습 중 기존 능력 보존은 아직 부족하다. 완성된 영어 Base라고 판단할 수 없다. 최근 보존 복구 실행은32단계에서 안전 종료했고 현재 실행 중인 학습은 없다.

## 해결·확인한 실행 문제

- mixed 출력 토큰이 pointer와 우연히 일치했다고 cursor를 시작하지 않도록 제한하고 회귀 검사했다.
- 개발용 Exact 생성은 원래 질문에서 한 번 승인하고, 승인 뒤 기존 cursor+EOS를 사용한다. 승인 전 pointer mixture와 자기 생성 prefix의 재승인을 제거했다. 거절 후 실제 Base 응답을 생성한다.
- 학습 입력이 실제 registered-record 생성의 segmented prefix 토큰과 일치하도록 구성했다. 이 데이터640문항은 문자열 전체를 한 번 인코딩한 결과와 달랐으므로 저장 텐서를 런타임 토큰으로 재구성했다.
- 실제 active/supervised/내용/EOS/자료 반복·손실을 기록하고 전체 optimizer step 분모를 사용한다. 토큰 비율이나 weight mass를 gradient 기여율로 부르지 않는다.
- model/AdamW/RNG/진행 위치 복구, 고정 예산·중복 실행 금지·독립 프로세스 감독을 구현했다. 최신 실제 model+Adam 저장·복원 동일성을 확인했다. CPU fixture의 다음 update 동일성도 통과했다.

## 데이터 감사 결론

검토 QA64개 중46개 유지,16개 명료화/교정,2개 교체했다. 수정16개 모두를 오답으로 세지 않는다. 명백한 잘못된 정답 label은2개였다. 문서 분리·span·alias·prefix·EOS·저장 텐서를 검증해 별도 수정 후보를 사용했다. 이 새 후보의 문제를 과거 모델 부진의 원인으로 확정하지 않는다.

하지만 QA는26기사, 고유 정답 내용247토큰으로 작다. TinyStories도 좁은 합성 이야기 자료다. 재생 횟수 증가는 고유 데이터 증가가 아니며, 현재 자료는 학습 반응을 보는 진단에는 유용하지만 넓은 영어 Base를 완성하기 위한 규모·다양성을 충족했다고 볼 수 없다.

최신 보존 후보에는 일반 글64/Python32/JSON32를 추가했다. 이는 정답 label이 없는 교사 행동 보존 입력이며, 교사의 정답성을 보증하지 않는다. 평가 자료와 exact32-token 중복 및 기존 계획/validation 행을 제외했다. 과거 전체 pretraining의 의미적 누출·source epoch는 완전히 규명되지 않아 UNKNOWN이 남는다.
