# 사용 방법

이 묶음은 FDT를 Colab에서 로컬 Codex 프로젝트로 이식하기 위한 **프롬프트와 근거 자료**입니다. 로컬 이식을 마친 실행 프로그램이나 새로 학습한 모델이 아닙니다.

1. 이 ZIP을 새 작업 폴더에 풉니다. 기존 실험 폴더 위에 덮어쓰지 않습니다.
2. 로컬 Codex에서 이 폴더를 엽니다.
3. 다음 지시를 전달합니다.

```text
이 폴더의 FDT_Codex_Local_Prompt_2026_10_26.md 전체와 동봉 자료를 읽고 그대로 진행해.
Colab 전용 의존성을 제거한 별도 로컬 프로젝트를 만들고, 원본은 보존해.
실제 내 PC의 CUDA 환경을 확인하고, 프롬프트의 제한된 smoke·저장·fresh reload 검증까지 완료해.
이 채팅과 관련 과거 대화는 접근할 수 있는 범위에서 확인하되 읽지 못한 내용은 추정하지 마.
장기 학습은 준비를 마친 후 내가 학습 시작을 지시하면 진행해.
```

`sources/`에는 설계 명세, 개정 통합 논문, 이전 인계, 코드 감사, 과거 상태·실험 요약, 별도 corpus 계획을 넣었습니다. `original_source_bundle/`에는 실제 source digest를 확인한 원본 recovery v2 ZIP이 있습니다. 이 ZIP 안의 notebook은 원본 보존용이며 새 실행에 Colab을 요구하지 않습니다.

과거2240회 학습의 가중치 파일은 이 묶음에 없습니다. 유효한 checkpoint를 별도로 찾고 검증하지 못하면 새 초기값으로 시작해야 합니다. CPU fixture29개 PASS와 명세 검사28개 PASS는 실제 GPU 학습 결과와 구분해야 합니다.

`SHA256SUMS.json`은 인계 파일의 바이트 무결성 확인용입니다. checkpoint 저장 완료·모델 재현성의 증거를 대신하지 않습니다. 상세 출처·확인 범위는 `EVIDENCE_NOTES.md`를 읽습니다.
